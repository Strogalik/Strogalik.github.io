# Импорт мобильного интерфейса в Figma — v4

Базовый мобильный фрейм: **390 × 844 px**.

## Режим импорта

```text
http://localhost:8080/?figma=1
```

На странице выводятся:

1. Экраны руководителя.
2. Экраны менеджера.
3. Экраны логиста.
4. Компоненты торгового контура.
5. Отдельные фреймы модальных окон редактирования склада, коллекции, товара, остатка и контрагента.

## Рекомендации

1. Импортировать страницу через HTML-to-Figma.
2. Проверить Montserrat после импорта.
3. Превратить шапку, нижнюю навигацию, карточки KPI, статусы и строки справочников в компоненты.
4. Создать variants `Leader`, `Manager`, `Logistics` без изменения базовой цветовой темы.
5. Создать variants плановой карточки: `Good`, `Watch`, `Bad`.
6. Bottom sheets импортировать как overlay-компоненты.
7. Для длинных форм использовать Auto Layout без фиксированной высоты.

## UI-система

- Montserrat 400 / 500 / 600 / 700.
- Минимальная зона нажатия: 42–48 px.
- Базовые отступы: 4 / 8 / 12 / 16 / 24 px.
- Desktop-таблицы на мобильном заменены карточками и вертикальными списками.
- Горизонтальный скролл используется только для коротких вкладок и фильтров.
- Анимации не являются обязательными для понимания интерфейса и не мешают импорту.
