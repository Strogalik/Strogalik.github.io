# TMS landing page — v4

Чистая адаптивная верстка без сборщика: HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Экранный режим на десктопе

При ширине от 1100 px и высоте от 800 px шапка фиксируется, а основной контент работает как отдельный экранный scroller:

- один шаг колеса — один следующий экран;
- каждый экран занимает всю доступную высоту под шапкой;
- соседние секции и их фон не видны;
- поддерживаются клавиши Page Up, Page Down, стрелки, Home и End;
- отзывы прокручиваются горизонтально независимо от вертикальной навигации.

На планшетах и телефонах используется обычная длинная страница без принудительного scroll snap.

## Перенос через HTML-to-Figma

Для импорта всей страницы откройте специальный режим:

```text
http://localhost:8080/?figma=1
```

В этом режиме фиксированный экранный scroller отключается, все секции становятся последовательными блоками, а изображения остаются локальными файлами в `assets/images`. Это надежнее для HTML-to-Figma-плагинов, чем внешние URL.

## Что заменить перед публикацией

1. В `script.js` замените `DEMO_URL` на настоящую ссылку демо CRM.
2. Подключите формы демо и отзывов к backend Django. Сейчас добавленные отзывы сохраняются только в `localStorage` текущего браузера.
3. При необходимости добавьте юридическое наименование, адрес, телефон и email компании в футер и политику конфиденциальности.
4. Перед production-публикацией подтвердите право использовать названия компаний и тексты отзывов.

## Что изменено в v4

- исправлена геометрия экранного скролла: шапка вынесена из scroll-контейнера;
- все десять основных экранов имеют одинаковую высоту и точно выравниваются по верхней границе под шапкой;
- удалены полосы и фоны соседних секций;
- сломанная бесконечная карусель кейсов заменена статичным коммерческим блоком со стоковой фотографией;
- добавлены локальные стоковые фотографии в кейсы, блок выгод, этапы демо и отзывы;
- изображения оптимизированы и хранятся внутри `assets/images`;
- карусель отзывов работает через нативный горизонтальный скролл и CSS scroll snap;
- стандартные emoji-иконки заменены локальными SVG-иконками;
- сохранен предоставленный логотип TMS;
- добавлен отдельный режим `?figma=1` для переноса через плагин;
- Montserrat: Regular 400 для текста, SemiBold 600 для пилюль и кнопок, Bold 700 для заголовков.

## Проверка

Проверено в Chromium:

- desktop 1440×900: высота шапки 72 px, каждый экран 828 px;
- все секции выравниваются по координате 72 px — сразу под шапкой;
- одно движение колеса переводит ровно на один экран;
- mobile 390×844: обычный вертикальный скролл, без горизонтального переполнения;
- JavaScript проходит синтаксическую проверку `node --check`.
