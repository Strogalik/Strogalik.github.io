# TMS — Управленческий контур

Новое коммерческое предложение: 10 статичных экранов 1920 × 1080 в стиле TMS Commercial. Это презентация состава решения, а не реализованная бизнес-система с авторизацией.

## Основа содержания
- Новый запрос: личный аккаунт дилера; доступ предоставляет директор; почта используется как логин; самостоятельная генерация пароля; ИНН, телефон и почта при регистрации; задачи, календарь с датами; зелёные / жёлтые / красные напоминания в списке клиентов.
- Предоставленные screenshots: сводка, аудиты, менеджеры, задачи, календарь и торговый контур на desktop/mobile. Демонстрационные числа и реальные имена из screenshots не публикуются.
- TMS Commercial: Montserrat, Deep Navy #000926, Sapphire #0F52BA, светлые surfaces и крупная презентационная типографика. public/TMS.svg — ранее предоставленный пользователем оригинал.
- Новая стоимость и сроки не указаны. Предыдущие 250 000 ₽ и агентская механика к этому предложению не относятся и не перенесены. Генератор/передача пароля, права и временные пороги напоминаний вынесены на согласование ТЗ.

## Запуск
Node.js 22.

```
npm install
npm run dev
npm run build
npm run export:html
```

## Просмотр и Figma
Обычная страница подгоняет масштаб всей презентации под ширину окна, не меняя композицию. Для импорта через Code to Figma используйте `?native=1` при viewport 1920 × 1080. Все тексты и surfaces — DOM/CSS, иконки — простые SVG. Нет форм, кнопок, регистрации или бэкенда. Пароли и персональные данные не собираются.

`preview.html` — статичный DOM из тех же React-компонентов. Шрифты подключаются с Google Fonts; бинарные файлы шрифтов в репозитории не распространяются. PDF содержит встроенные подмножества для корректного отображения.

## Публикация
GitHub Actions выполняет TypeScript/Vite build, проверяет реальные шрифты и геометрию, экспортирует 10 PNG и PDF, затем публикует dist в GitHub Pages. История предыдущего сайта сохранена Git-коммитами; текущее дерево полностью заменено новым КП.

## QA
`scripts/qa.py`: 1920 × 1080, минимум 20 px, отсутствие независимых текстовых пересечений и клиппинга, оригинальный logo, реальные Montserrat fonts, 10 PDF-страниц, проверка 1440 px и HTTP опубликованной страницы. Отчёт и изображения — в артефакте Actions `tms-management-visual-qa`.
