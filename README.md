# TMS ASUB — готовый SaaS, масштабирование продаж

12 экранов 1920 × 1080. Новый инвестиционный нарратив в коммерческом стиле TMS.

## Готовые материалы
- `preview.html` — статичная презентация с редактируемыми DOM-текстами, CSS-поверхностями и настоящим логотипом TMS. Масштабируется целиком под окно, без перестройки отдельных слайдов.
- `TMS_ASUB_SAAS_GROWTH.pdf` — 12 страниц 16:9, готовых к отправке.
- `full-visual-preview.jpg` — общий обзор.

## Источник вёрстки
- `src/slides.html` — единственный источник текста и структуры 12 экранов.
- `src/styles.css` — коммерческая визуальная система и печатные стили.
- `src/App.tsx` — минимальная React-оболочка для этой же DOM-презентации.
- `public/TMS.svg` — оригинальный загруженный логотип, без изменений.

## Локальный запуск React / Vite
```sh
npm install
npm run dev
```
Сборка: `npm run build`.
Статичный HTML из того же источника: `npm run export:html` (команда работает без сторонних зависимостей).

Полная npm/Vite-сборка в текущей среде не выполнялась из-за недоступности DNS npm. Проверены синтаксис TypeScript, готовый статичный HTML в Chromium, изображения всех кадров и PDF. React-оболочка не является отдельным макетом: она показывает тот же `slides.html` и `styles.css`.

## Code to Figma
Разместите вебверсию или запустите локальный сервер. Используйте `preview.html?native=1` и viewport 1920 × 1080. Каждый `.frame` имеет ровно 1920 × 1080, идентификаторы `screen-01` … `screen-12`.
Контент остаётся текстом и блоками, а не скриншотами слайдов. Нет Canvas, WebGL, фильтров, навигации, форм и фиктивных действий.

## Типографика
Montserrat 500/600/700 — основная гарнитура; Inter 500/600 — служебные данные. Большие суммы и знак ₽ — Montserrat 700. Содержательный текст от 20 px в исходном кадре.
В вебверсии шрифты подключаются из Google Fonts; также поддерживаются установленные локальные гарнитуры. Отдельные файлы шрифтов не входят в архив. В PDF необходимая типографика уже зафиксирована и доступ к интернету не нужен.

## Новая смысловая рамка
Готовый SaaS-продукт → текущие результаты → опыт применения → действующие партнёры → маркетинг как главный приоритет бюджета → измеримое масштабирование → подготовка к работе с госсектором РФ.
Сумма инвестиций, оценка компании, доля инвестора, календарь раунда и неподтверждённые прогнозы в презентацию не включены.

## Точность формулировок
См. `SOURCES_AND_ASSUMPTIONS.md`. Текущий заработок SaaS не назван MRR или прибылью: пользователь не уточнил период и состав показателя. Исторические проектные продажи отделены от SaaS. Госсектор и лицензирование показаны как план, не как выполненная подготовка.

## QA
`qa/QA_REPORT.json`: нативный размер кадров, минимальный кегль, пересечения независимых текстовых блоков, выходы за кадр, ошибки JavaScript и фактические гарнитуры Chromium.
`qa/PDF_QA.json`: 12 страниц, 16:9, проверка сохранности текста при PDF-экспорте и совпадения оригинального логотипа.
