# TMS × ALTDEKOR — исправления v7

## 1. Статусные пилюли в задачах

**Что изменено:**
- пилюли «Решение», «Нужно решение», «Контроль» и «В работе» увеличены;
- пилюля выровнена по центру всей карточки задачи по вертикали;
- текст внутри пилюли центрируется по обеим осям;
- на экране 360 px применяется отдельный компактный размер без выхода за карточку.

**Точные места:**
- `styles.css`, строки **1274–1314** — grid-структура карточки и центрирование пилюли;
- `styles.css`, строки **1365–1374** — размеры пилюль для экранов до 370 px;
- `app.js`, строка **655** — разметка карточки задачи.

## 2. Счётчики разделов задач

**Что изменено:**
- счётчики «5», «31 открыта» и аналогичные элементы получили увеличенную высоту и симметричные внутренние отступы.

**Точное место:**
- `styles.css`, строки **1315–1323**.

## 3. Кнопка «Создать задачу» перенесена перед списком

**Что изменено:**
- кнопка теперь идёт сразу после фильтров;
- только после неё выводятся «Обратить внимание» и «Задачи команды»;
- добавлен нижний отступ перед первым списком.

**Точные места:**
- `app.js`, строки **630–637** — новый порядок элементов;
- `styles.css`, строки **1324–1331** — отступы и высота кнопки.

## 4. Графики логиста

**Что изменено:**
- исправлен расчёт координат: линия больше не уходит за пределы SVG;
- значения нормализуются в пределах видимой области;
- добавлены сетка, заливка, точки данных и корректная нижняя база;
- подписи дат вынесены под график и не пересекаются с линией;
- количество колонок подписей автоматически соответствует количеству дат;
- для компактной аналитики используется отдельная уменьшенная высота.

**Точные места:**
- `app.js`, строки **1109–1125** — новый расчёт и разметка графика;
- `styles.css`, строки **1332–1363** — визуальная область графика;
- `styles.css`, строки **1376–1377** — компактный график внутри аналитической карточки.

## Проверка

Проверено на ширинах **360 px** и **390 px**:
- горизонтального переполнения нет;
- кнопка создания задачи расположена выше первого списка;
- отклонение центра пилюли от центра карточки: менее **0,1 px**;
- SVG полностью помещается в контейнер графика;
- подписи располагаются ниже графика;
- ошибок JavaScript не обнаружено.
