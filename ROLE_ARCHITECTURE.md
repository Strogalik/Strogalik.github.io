# Ролевая архитектура мобильной CRM / АСУБ v4

## Руководитель

| Модуль | Доступ |
|---|---|
| Главная | Сводка компании, регионы, команда, блок внимания |
| Отчёты | Все регионы и магазины, месяц и год |
| Магазины | Все точки, оценка сети, история и графики аудитов |
| Аудиты | Только просмотр и аналитика, создание запрещено |
| Задачи | Свои, команды, просрочки, задачи руководителя |
| Клиенты | Все доступные по компании и роли |
| Звонки | Все доступные звонки и AI-анализ |
| Торговый контур | Заказы, аналитика, каталог и справочники |
| AI | Ассистент руководителя, отчёты и черновики задач |

## Менеджер

| Модуль | Доступ |
|---|---|
| Главная | Только личные показатели и свои задачи |
| Отчёты | Только свои магазины и личная аналитика |
| Магазины | Только закреплённые точки |
| Аудиты | Только свои аудиты, создание доступно |
| Задачи | Только назначенные пользователю; цикличные появляются автоматически |
| Клиенты | Только закреплённые клиенты и дилеры |
| Звонки | Только личные звонки и личная аналитика |
| Торговый контур | В объёме прав, выданных backend |
| AI | Помощник по продукции и контекстный AI магазина |

## Логист

| Модуль | Доступ |
|---|---|
| Операционная сводка | Отгрузки, заказы, склады и товарные показатели |
| Торговые точки | Рейтинг по плану и выручке |
| Заказы | Статусы, состав, оплата, доставка и отгрузка |
| Аналитика | Выручка, объём, заказы, контрагенты и динамика |
| Каталог | Единая точка входа в товары, коллекции, остатки и склады |
| Справочники | Создание и редактирование в рамках выданных прав |
| CRM / аудиты / звонки | Недоступны |

## Цветовая логика

Роль не меняет фирменный цвет интерфейса. Все профили используют единую синюю UI-систему. Семантические цвета применяются только к состояниям данных:

- зелёный — показатель в норме;
- янтарный — зона риска;
- красный — критическое отклонение;
- синий — нейтральное действие или навигация.

## Обязательные backend-проверки

- Роль и компания проверяются на каждом API-запросе.
- Региональный и объектный доступ не определяется только интерфейсом.
- Endpoint создания аудита запрещает действие руководителю и логисту.
- Менеджер не получает данные чужого магазина изменением URL или ID.
- Логист не получает CRM, звонки и аудиты через прямой URL.
- AI использует ту же матрицу прав, что и штатные отчёты.
