# TMS × ALTDEKOR — мобильная CRM / АСУБ v6

Mobile-first HTML/CSS/JS-прототип по desktop-экранам и ТЗ ALTDEKOR редакции 4.0.

## Ролевые профили

### Руководитель направления

- сводные отчёты, регионы, магазины, команда и все доступные звонки;
- задачи руководителя и блок «Обратить внимание»;
- аналитика аудитов без возможности создать или начать аудит;
- AI-ассистент руководителя.

### Менеджер

- только свои магазины, клиенты, звонки, задачи, аудиты и отчёты;
- создание аудита только по закреплённым точкам;
- AI-помощник по продукции.

### Логист

- операционная сводка, рейтинг торговых точек и торговый контур;
- заказы, аналитика, каталог, склады, коллекции, товары, остатки и контрагенты;
- единая синяя UI-система, как у руководителя и менеджера;
- цвет карточки выполнения плана зависит от результата, а не от роли.

- Каталог связывает товары, коллекции, остатки и склады.
- Исправлено активное состояние нижней навигации на всех экранах торгового контура.

## Запуск

```bash
cd TMS_ALTDEKOR_mobile_ui_v6
python3 -m http.server 8080
```

```text
http://localhost:8080
```

Роли:

```text
http://localhost:8080/?role=leader
http://localhost:8080/?role=manager
http://localhost:8080/?role=logistics
```

Примеры прямых экранов:

```text
http://localhost:8080/?role=logistics#shop-catalog
http://localhost:8080/?role=logistics#shop-products
http://localhost:8080/?role=leader#tasks
```

Для проверки модального окна товара:

```text
http://localhost:8080/?role=logistics&sheet=product-edit#shop-products
```

Все экраны для импорта в Figma:

```text
http://localhost:8080/?figma=1
```

## Технические ограничения

- Данные демонстрационные и не подключены к Django/API.
- Ролевое разграничение в прототипе визуальное; backend обязан проверять роль, компанию, регион и объект на каждом запросе.
- Телефония, 1С, push, offline sync и AI требуют backend-интеграций.
- AI не изменяет данные без явного подтверждения пользователя.
