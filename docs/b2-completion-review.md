# TMS V6 B2 · выполненная итерация

Внутренние страницы и навигация доработаны поверх существующего сайта. A4.8 и внешний вид главной B1 одобрены и сохранены. Stage B остаётся **partial**: 3 независимых FAIL замороженного футера не скрыты. Публичного deploy и реальных отправок не было.

## Что изменено

Продуктовые страницы получили спокойные вертикальные раскрытия, один релевантный проект и реальный CTA. /cases — отдельный доступный выбор трёх кейсов с прямыми ссылками. Три страницы кейсов сохраняют факты и оговорки. Разработка и партнёры используют раскрытия вместо нумерованных колонок; about/privacy оформлены читаемыми страницами. Внутренние компоненты и CSS изолированы.

Shared header ведёт на /#solution, /#products, /#cases, /#cooperation, правильно передаёт focus и закрывает меню; menu→form открывает один диалог. Внешний вид шапки не изменён.

В QA обнаружен выход CTA индекса кейсов за его блок при большом тексте. Внутренняя сетка исправлена: содержимое участвует в естественной высоте CSS grid. Все три состояния проверены при тексте 200%+spacing, финальная сетка — в native Safari.

## Native Safari и настоящий zoom

На этом Mac отдельно проверены native Safari: CRM раскрытие/якорь, межстраничное меню, кейс-диалог и Escape/focus, меню→форма. Через Page Menu выбран настоящий **200% browser zoom**: проверены меню, форма, выбор кейса и прямая страница. Затем масштаб возвращён к 100%. После финального CSS исправления проверены три состояния индекса кейсов на desktop Safari. Скриншоты и границы проверки — native-safari/report.json. Это scoped smoke, не вся Safari-матрица.

Физический телефон, screen reader, Firefox и автоматизированный WebKit: **NOT RUN** (последние два браузера не установлены). AX-inspection не считается VoiceOver. Якорь «Результат» на странице школы при 200% отдельно не подтверждён.

## Что остаётся

Футер: подготовлен b2-footer-candidate.patch, изолированный before/after устраняет 3 overflow, обычный вид 12/12 совпал. По прямому запрету задания в protected source не применён; требуется отдельное решение владельца. Stage B partial до разрешения и повторного regression.

Публичный запуск blocked: юридический текст не согласован, production delivery/upstream compatibility не подтверждены, HTTPS origin/indexing/hosting не настроены. /auto/ и /nedv/ отвечают HEAD 200, их будущая обработка перед Next catch-all требует проверки хостинга.

Полный source собран заново; результат проверки извлечённой копии находится в b2-clean-source-check.json. ZIP не содержит env, QA сырья, внутренних пакетов и файлов шрифтов. Метрики npm-font fallback могут отличаться от рабочих локальных WOFF2; визуальные сравнения 168/168 относятся к рабочему preview с оригинальными шрифтами.
