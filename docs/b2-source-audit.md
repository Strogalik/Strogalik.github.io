# B2 · актуальная карта источников

Работа выполнена в существующем outputs/tms-site. Git-репозитория в проекте и доступных родительских каталогах нет; git status не применим. До изменений сохранены 276 файлов с хешами в приватном work/b2-before; архив задания не накладывался на проект.

Актуальное основание: PROMPT_FOR_CODEX_TMS_V6_B2_COMPLETION.txt и 00_START_HERE, AUDIT_B1, brief/01, brief/02, approval/FOOTER_EXCEPTION_PROPOSAL из B2-пакета. Пакет — задание и evidence, не исходники. В публичный сайт внутренние документы/база ссылок/сырые материалы не копировались.

Источник кейсов — неизменённый content/cases.public.json. Все три проекта сохранены: B2B-оптовик, производитель покрытий, онлайн-школа. Периоды, ограничения, значения «до» и контекст индивидуального внедрения сохранены. Исключённые LTV/расходы не возвращены; новых клиентов/отзывов/обещаний нет.

Офферы и факты берутся из текущего content. Короткие пояснения продуктовых раскрытий отредактированы по существующим функциям/процессу; новых тарифов, цен, сроков и гарантий нет. CRM и OMS по подписке, разработка отдельно. /demo остаётся вторичным учебным примером.

Новые InternalViews, InternalTopics, InternalCases и internal.module.css изолированы от принятой главной. Общие Sections оставлены для существующих потребителей, B1Sections не изменён. ApprovedViews изменён только для технического поведения навигации. Данные, математика, API и pinned зависимости неизменны.

Оригинальные локальные шрифты/логотип сохранены. Полный source ZIP исключает шрифтовые бинарники: bootstrap использует закреплённые @fontsource Inter/Montserrat из npm ci. Это другой способ поставки шрифтов, побитное/метрическое равенство с исходными WOFF2 не обещается. Лицензии приложены.

Актуальные доказательства: b2-completion-review.md, b2-route-matrix.json, b2-design-preservation.json и qa/v6-b2. Старые отчёты имеют исторический статус.
