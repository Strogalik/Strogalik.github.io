# B5 — карта данных и согласий

| Контур | Действие и данные | Хранение / получатель |
|---|---|---|
| Информационное уведомление OFF | Только явное «Понятно» | Прежний localStorage tms:cookie-notice:v1=closed; не согласие на аналитику. |
| Необязательная аналитика | Отдельные равнодоступные разрешение/отказ для конкретного профиля | tms:analytics-choice:v1: schemaVersion, decision, profileDigest, consentVersion, consentHash, chosenAt, expiresAt. Нет контактов, UTM, истории или fingerprint. |
| Обращение | Имя и email ИЛИ телефон; необязательные компания/запрос; существующие product/topic/case/context; путь без query; 5 текущих UTM только при submit | POST /api/lead с самостоятельным unchecked checkbox. Нет localStorage-черновика. Подтверждённый success только после upstream. |
| Receipt | Серверные версия/hash/время/источник согласия | В payload upstream; durable storage и сроки у получателя требуют подтверждения L4. Не отправляется в аналитику. |
| Public config | GET /api/analytics-config: разрешённый профиль, ID и digest или единое OFF | no-store, без контактов и секретов, cookies credentials:omit; это не endpoint сбора статистики. |
| Предлагаемая Метрика | После операторского разрешения и актуального grant: только фиксированные публичные пути без query/hash; referrer максимум origin, title пуст | В B5 только перехваченный test double с синтетическим ID; реального получателя runtime нет. |

180 дней — технический максимум browser choice, не требование закона и не срок CRM. Посещение не продлевает срок. Истёкшая, повреждённая, неизвестная или не соответствующая профилю запись не разрешает загрузку. При отказе storage используется память текущего открытого документа; reload не восстанавливает grant. При смене профиля прежний выбор удаляется, без переноса другому сервису.

Отзыв сохраняет denied, инвалидирует continuation загрузки, запрещает новые события, выполняет disableYaCounter + destruct, очищает только доступные сервисные идентификаторы из allowlist. Событие storage синхронизирует вкладки без reload и потери введённой формы. Удаление HttpOnly/чужих third-party файлов и прошлой статистики не обещается.

Текущие UTM обращения остаются в lib/utm.ts без изменений и не используются адаптером. Исторический lib/analytics.ts остаётся только типами — никакой рекламной воронки.
