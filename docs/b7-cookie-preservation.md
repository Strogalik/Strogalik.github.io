# B7 — сохранность механизма cookies

Статус: awaiting_owner_review. Обновлена только оболочка CookieNotice и четыре разрешённых строки `off.title/text`, `available.title/text` в privacy-ui.json.

## Что осталось источником истины

PrivacyStore, PrivacyProvider, profile/config/choice/runtime, сроки и версии выбора, consent receipts/hash, формы и серверная валидация не изменены. Актуальная проверка `qa/v6-b7/locked-audit.json`: 33 защищённых файла без отличий; остальные поля privacy-ui.json совпадают.

OFF сохраняет только штатный `tms:cookie-notice:v1=closed`. Это не grant. ShowAgain, memory-only, storage events, отказ и отзыв продолжают использовать B5. Разрешение завершает серверную проверку config до исчезновения уведомления. Никакого счётчика при показе, скролле, входе или закрытии панели.

## Отдельное визуальное присутствие

Вход: 280 ms desktop / 220 ms compact, подъём 9/6 px. Выход: 170 ms, 6/4 px. Текст остаётся непрозрачным; прозрачность всей панели не анимируется. Исчезающее состояние сразу inert и aria-hidden, pointer events выключены. Отказ/отзыв выполняется до эффекта. Новый видимый state отменяет старый эффект; resize, reduced-motion и скрытие документа завершают визуальное состояние без очередей.

Резерв конца страницы и scroll-padding измеряются по действительной панели. Cleanup блокирует и отложенный focusout callback: найденный при первом прогоне дефект остаточного отступа исправлен. При фокусе во внешнем input/textarea, модальном диалоге или сжатом visualViewport уведомление временно скрыто без записи выбора. Если панель при крупном тексте занимает более 55% высоты окна, она становится обычным блоком в конце документа; содержимое и все действия доступны без вложенного скролла. Focus при dismiss меняется только если находился внутри исчезающей панели.

Материал: одна заливка 96%, статичный blur 12 px, обводка и короткая тень. Нет SDK, WebGPU, scale текста, живых бликов, автозакрытия или нового окна юридических настроек. No-blur/reduced-transparency и forced colors дают читаемый fallback. Обычный текст 16 px, кнопки не ниже 44 px.

## Проверка

Свежие OFF/enabled-stub кадры: `qa/v6-b7/cookies/`. Видео enabled-stub: `qa/v6-b7/motion/*-cookies-enabled-stub.webm`. Все запросы к внешним сервисам перехвачены тестовым маршрутом: код Метрики из сети не загружался, данные наружу не уходили. В QA использован синтетический ID в переменных дочернего процесса; .env не менялся.

Проверки B7 покрывают OFF, отказ, отложенную проверку grant, успешный локальный stub, немедленный отзыв, ShowAgain, focus/modal suppression, очистку резерва, text200/spacing/forced/low viewport. Полная B5 регрессия дополнительно проверяет profile change, expiry, storage denied, cross-tab, late loader, offline, fail-closed, no-JS и независимость согласия формы. Точные итоги каждого запуска — в motion review и JSON, не в исторических B5/B6 отчётах.

Native Safari, физическая экранная клавиатура, VoiceOver и настоящий browser zoom не запускались. Уменьшение viewport и CSS text200 не называются этими проверками. Внешние юридические и эксплуатационные условия B5 анимациями не закрыты.
