## Движение

Неизменный hero-motion контролирует общий clock. Снято 16 фаз на 1920/430/390: 0,120,240,480,3000,3120,3240,3480,4490,4500,4540,4620,4740,4920,5100,6000ms. **48/48** одинакового размера, ни одного канала с отличием >2/255; этот допуск взят из существующего A4.8 material-audit, не введён после результата. Все пиксели сравниваются, без масок сообщений/материала. Реальные значения clock проверены отдельно. Белая OMS входит с 4500ms.

На desktop записано 30.263s, на 390px — 17.811s. Пауза стабильна в обоих случаях; wide продолжает тихое парение; compact после 6000ms имеет 0 собственных idle callbacks/paint. Offscreen проверен настоящим scrolling/IntersectionObserver; document.hidden проверен симуляцией API на 10s, не настоящим background-tab тестом. Пауза пользователя сохраняется. Wash внутри стабилен; на краю стекла headless raster меняет не более 2/255, что отражено в phase-diff-probe.

NoJS/reduced motion, forced colors, отсутствие blur и клавиатура проверены browser-тестами. Native Safari проверен отдельно в ограниченном наборе действий, не всей матрицей. Известный дефект 200% текста+spacing в замороженном футере и минимальное неприменённое предложение описаны в основном отчёте.
