Запуск: `npm run build`, затем `node scripts/review-v6.mjs`. Адрес: http://127.0.0.1:3200/review/v6. Сервер привязан к 127.0.0.1. Без opt-in маршрут возвращает 404. Галерея: `qa/v6-a3/index.html`.

Продолжен существующий A2. Все 16 файлов эталона совпали с рабочей папкой до изменений. Git-метаданных нет; перед работой сохранены 146 файлов и SHA256. Старые источники не распаковывались поверх сайта. Before сняты с текущей сборки A2 в этой итерации, а не взяты из прежнего отчёта.

## Изменения

- В меню, мобильном выборе и метке сцены — только CRM, OMS, Разработка. Смысловые упоминания продаж/исполнения и все шесть исходных тем сохранены.
- Общие треки связывают intro, меню, текст и визуал. На desktop меню 208 px, текст 320–360 px, промежутки 32 px и 48–56 px. Метка направления всегда начинается у первой CRM, H3 ниже на 16 px. Убраны `align-self:end`, зависимость текста от высоты соседнего объекта и прежнее вертикальное центрирование всей секции.
- Intro центрирован относительно реальной белой поверхности. В custom-solution сохранились белая готовая основа, тёмное расширение и его смещение; остальные пять объектов сохранили самостоятельные образы.
- Темы получили полноширинные кнопки: границу, отдельный hover, выбранную строку и видимый focus. Короткие названия направлений на mobile и две темы активного направления; ручная клавиатурная навигация сохранена.
- Контролируемое раскрытие использует кнопку с `aria-expanded`/`aria-controls` и SVG plus/minus. Нативного marker нет. На просторном desktop вся copy-группа перемещается за 260 ms: подъём равен минимуму из 22% фактической добавленной высоты, 32 px и свободного зазора над группой за вычетом 24 px. Intro, меню и визуал остаются на своих местах. Нет программной прокрутки.
- Ниже 1251 px, при высоте менее 900 px или корневом шрифте более 18 px подъём отключён. Секция растёт по содержимому. На tablet visual идёт после заголовка; на mobile — заголовок, visual, body, раскрытие/действия. Быстрое повторное нажатие разворачивает текущий CSS-переход; смена темы закрывает прежнее раскрытие; resize сохраняет выбор и состояние.
- Кнопка шапки сохраняет авторский градиент, над ним слой hover #1A74D2 с opacity-transition 160 ms. Белый текст, hit area, focus и pressed доступны. Hero CTA не перекрашен. Reduced-motion отключает эти переходы.
- Единственные изменения ReviewV6.tsx — метки версии A2 → A3. HeroStory.tsx, тексты сцен, футер, контакты, V5-маркетинг, demo, калькуляторы, lead API, review gate, шрифты и lockfile сохранены.

## Ограничения

- Playwright WebKit не установлен: запуск недоступен. Safari, физические устройства и screen reader не проверялись.
- Настоящий browser zoom 200% не запускался в A3; выполнен CSS text/reflow test, не подменяющий zoom.
- Headless visibility handler проверен через симуляцию visibilitychange, не через физическое переключение вкладок.
- Lighthouse и полный этап B не запускались. Production delivery, платные интеграции и публичный deploy не выполнялись; это не блокирует локальное согласование A3.
- После согласования потребуется отдельный этап B; сейчас он не начат.

## Воспроизведение артефактов

После build запустить локальный review. Для gate-теста дополнительно запустить `PORT=3201 TMS_HOST=127.0.0.1 TMS_DESIGN_REVIEW=0 npm run start` с отключёнными upstream/analytics.

`node scripts/capture-v6.mjs` создаёт viewport/section screenshots и общую запись. `node scripts/capture-v6-a3-motion.mjs` создаёт геометрию всех сцен и движение desktop/mobile. `node scripts/contrast-v6.mjs`, затем `python3 scripts/contrast-v6.py` измеряют текст. Артефакты сохраняются в `qa/v6-a3`, A2 не перезаписывается. Для этих проверок нужен запуск локальных сокетов/Chromium; начальный sandbox-запуск unit был запрещён средой, повтор с loopback-доступом прошёл.

Review ZIP содержит доказательства и отчёты. Patch ZIP содержит только изменённые исходники/документы с before/after manifest; он не является полным сайтом, не содержит зависимостей, сборки, секретов, файлов шрифтов или внутреннего пакета задания.
