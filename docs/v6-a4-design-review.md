# TMS V6-A4 · содержание без повторяющей иллюстрации

9 октября 2026. **awaiting_owner_approval**, **stageBStarted:false**. Вариант без правого визуала предложен для оценки владельцем; весь дизайн не объявляется утверждённым.

## Результат

Продолжен существующий локальный A3. Все 8 хешей реализации из approval A3 совпали. Перед записью сохранена копия 151 файла с SHA256. Git-метаданных нет. Внутренний пакет распакован отдельно от приложения/public; старые исходники поверх проекта не накатывались.

Работающий адрес: http://127.0.0.1:3200/review/v6. Запуск: `npm run build`, затем `node scripts/review-v6.mjs`. Без opt-in — 404; сервер слушает только loopback. Preview-форма выполняет лишь локальную проверку, без доставки/analytics.

Продуктовый блок теперь состоит из двух колонок: принятого меню шириной 208 px и одной содержательной области. Между ними 32 px. Текстовая группа имеет max-width 640 px; свободное поле справа естественное, третьего grid-track или скрытого StoryScene в DOM нет. Заголовки на просторном desktop занимают две строки. Отдельной карточки вокруг содержания нет.

Для активного блока создан `content.module.css`; старые `StoryScene.tsx` и `story.module.css` сохранены без изменений и не импортируются активным блоком. Это позволяет сохранить прежние иллюстрации в истории исходников, не оставляя скрытый focusable DOM или их декоративную подложку на странице.

Верхний заголовок и вводный абзац имеют отдельную двухколоночную сетку. **Выбранное прочтение центровки:** первая строка intro справа на верхней линии «Решения TMS» слева; строки intro по-прежнему центрированы. Это трактовка для нового preview, не ранее утверждённые владельцем точные координаты. Intro сохранён дословно и не меняется при выборе темы. Отдельные кадры: `screenshots/intro-1920.png` и `intro-1440.png`. Ниже 901 px блоки идут вертикально.

Сохранены все шесть тем, существующие ссылки, CTA, клавиатура, focus, выбор при resize, SVG plus/minus и контролируемое раскрытие A3. Высота раскрытия и подъём заново измеряются ResizeObserver по реальному тексту новой ширины: старого значения в пикселях нет. На просторном desktop подъём ограничен 22% добавленной высоты, 32 px и свободным зазором до intro за вычетом 24 px. На тесном экране/при крупном корневом шрифте подъёма нет. Текст свободно увеличивает секцию. Нет автопрокрутки и автоматического выбора тем.

Mobile: короткий выбор трёх направлений, две темы текущего направления, затем H3 → body → раскрытие → CTA/ссылка. Между H3 и body 16 px, без документа, пустой рамки или spacer.

## Воспроизведение и выдача

Для gate-off проверки дополнительно запустить `PORT=3201 TMS_HOST=127.0.0.1 TMS_DESIGN_REVIEW=0 npm run start` с пустыми upstream и analytics. Затем выполнить браузерный набор.

`node scripts/capture-v6-a4.mjs` снимает текущий A4; флаг `--before` предназначен только для запуска на A3 до правок. `node scripts/verify-v6-a4.mjs` сравнивает сохранённые before/after и проверяет измерения. Не запускать `--before` на A4 поверх зафиксированного before.

`qa/v6-a4/index.html` — галерея. Review ZIP содержит её, снимки, записи и отчёты. Patch ZIP содержит только фактически изменённые/новые исходники и документы с before/after SHA256; это не полный сайт. В обоих архивах нет секретов, зависимостей, сборки, файлов шрифтов или внутреннего пакета.
