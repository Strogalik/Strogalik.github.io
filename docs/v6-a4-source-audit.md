# Source audit · TMS V6-A4

9 октября 2026. Продолжена рабочая папка tms-site. Git-метаданных нет; перед правками сохранён снимок 151 файла с SHA256. Все 8 заявленных хешей реализации A3 совпали с рабочей базой. Предыдущие архивы не применялись поверх проекта.

## Границы изменений

Из существующих файлов изменены только:

- `README.md`
- `playwright.v6.config.ts`
- `tests/review-v6.spec.ts`
- `components/review-v6/StoryExperience.tsx`
- `components/review-v6/story-content.ts`
- `components/review-v6/StoryCopy.tsx`
- `components/review-v6/ReviewV6.tsx`

Добавлены изолированный `content.module.css`, два A4-скрипта съёмки/верификации, три документа A4 и новая QA-галерея. Старые материалы A3 сохранены как история. Patch содержит исходники/документы, review — доказательства проверки.

144 остальных файла базового снимка совпадают по SHA256. В частности, не изменены app/, lib/, public/, package.json, lockfile, HeroStory, StoryScene, story.module.css, review.module.css, запуск preview и существующие API/калькуляторы/данные кейсов. Полный список: `qa/v6-a4/isolation-audit.json`.

StoryCopy отличается только импортом изолированного CSS: логика измерения и раскрытия прежняя. ReviewV6 отличается только меткой A3 → A4. В story-content единственная правка — «Сначала разбираем процесс и нужный результат, затем…». Уникальный смысл результата перенесён из снятого визуала в существующее explanation; новых продуктовых утверждений нет.

## Источники и ограничения

Актуальное задание — PROMPT_FOR_CODEX_TMS_V6_A4.txt и пакет V6_A4_CONTENT_FOCUS: 00_START_HERE, DECISIONS, ACCEPTANCE, утверждённая навигация и материалы A3. Пакет хранится вне приложения/public. Содержимое пакета не является исходным кодом сайта; приложенный story-content использовался для сверки, не для отката.

Использованы только существующие локальные шрифты и бренд-материалы. Новые внешние библиотеки, изображения, шрифты и сетевые сервисы не добавлялись. В поставляемых архивах нет файлов шрифтов, env, зависимостей, сборки или внутреннего пакета. Отчёты относятся к свежему запуску A4, а не к старым PASS A3.

Клиентские JS-файлы текущей сборки проверены по четырём явным маркерам внутреннего пакета; совпадений нет. Это проверка конкретной утечки, не обещание исчерпывающего сканирования всех секретов. Review gate, отсутствие analytics и отсутствие реальной отправки review-формы проверены браузерным набором.
