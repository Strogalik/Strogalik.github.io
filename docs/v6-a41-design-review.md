## Что изменено

Продолжен текущий A4. До записи сохранён снимок 157 исходных файлов с SHA256, затем сняты реальные before A4. Git-метаданных в рабочей папке нет. Старые архивы не применялись.

Вводный абзац полностью удалён из StoryExperience и данных раздела, никуда не перенесён. Верх раздела теперь обычный block с «Решения TMS» и «Начинаем с вашей задачи»; прежних двух колонок, пустого grid-элемента и высоты абзаца нет. Его выравнивание больше не проверяется как требование.

На ширине viewport от 1251 px двухколоночная сетка использует меню 208 px, промежуток `calc(32% - 208px)` и оставшуюся содержательную область. Вся copy-группа начинается на 32% внутреннего контейнера; meta, H3, body, раскрытие, CTA и вторичная ссылка имеют общую левую ось. Ширина чтения по-прежнему ограничена 640 px. Нет горизонтального transform, absolute positioning, индивидуальных отступов тем или третьей колонки.

На ширинах 901–1250 px сохранён промежуток 32 px. На mobile остаётся обычный вертикальный поток, три направления и две темы текущего направления. Удаление абзаца сокращает раздел по содержимому. На 1024 px заголовок раздела теперь занимает одну строку вместо двух внутри старой половинной колонки; меню естественно поднимается вместе с рабочей областью на 50.6 px, без искусственного spacer. Его ширина, горизонтальная позиция, оформление и интервалы не менялись.

## Просмотр и воспроизведение

Preview: http://127.0.0.1:3200/review/v6#products. Запуск после сборки: `node scripts/review-v6.mjs`. Для gate-off теста второй сервер: `PORT=3201 TMS_HOST=127.0.0.1 TMS_DESIGN_REVIEW=0 npm run start` с пустыми upstream и analytics.

Галерея `qa/v6-a41/index.html` содержит сравнения closed/open одинаковых viewport, исходные PNG, полные mobile-разделы, видео и журналы. full-open — полная секция с увеличенной высотой viewport, не первый экран телефона. Контактные листы — сетки неизменённых снимков для обзора; оригиналы доступны отдельно. `--before` запускать только на A4 до правок, не поверх сохранённых before после обновления.

Review ZIP — визуальные материалы и отчёты. Patch ZIP — только изменённые/новые исходники и документы с before/after SHA256. Перед применением сверить хеши и сохранить свои правки. Этап A остаётся на согласовании; этап B не начат.
