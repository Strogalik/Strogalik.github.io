## Что изменено

Desktop: тематические строки матовые, без постоянной обводки и синей полосы. Ширина по содержимому, общий предел 288px, Inter 18px, поля 18×24px, промежуток 10px. Выбранность обозначена Sapphire-текстом, светлой поверхностью и SVG-галочкой. Keyboard focus остаётся отдельным. Названия CRM / OMS / Разработка — обычные заголовки групп.

Читающая колонка сохраняет ширину до 640px и прежнюю общую ось на широком desktop. Зазор плавно интерполируется от 32px; нет скачка 1250/1251. Body 19px desktop / 18px mobile; раскрытие 18/17px. H1/H2/H3 не увеличены. На коротком экране секция растёт по содержимому.

Hero: одна почти матовая оболочка, внутри две поверхности сообщений. Оригинальный локальный SVG даёт фон для рефракции; ни текст, ни форма, ни страница целиком не захватываются. Сообщения 19px с полями 20×24px на desktop, 17px с полями 16×18px на mobile. Входящее тёмное, исходящее светлое. Текст остаётся семантическим DOM и не получает фильтр. Внешнее окно не является SDK surface и не использует backdrop-filter.

Встроен точный `@glass-sdk/liquid-glass@0.0.1`, DOM API, одна сцена, maxSurfaces=2. Regular, motion=none, interactive=false, fluid=false; radius 24/20, refraction 6/3. SDK сам заменяет CSS radius на совпадающий clip-path. Свой reveal 380ms, один clock; пауза фиксирует progress и opacity, продолжение сохраняет время, повтор — один цикл. Убрано перемещение поверхности при reveal, чтобы не смещать sampled geometry.

**P1 deferred:** мобильная капсула остаётся проверенным CSS-вариантом. Реальное мобильное устройство и WebKit недоступны; второй GPU-кандидат не добавлен без нужной проверки.

Новые снимки просмотрены: все шесть тем в контактных листах 1920/1728/1440 и раскрытия 390/430, полные Hero/CSS/SDK, DPR2 и края сообщений. Контактные листы уменьшены для обзора; оригиналы имеют указанный CSS viewport. До/после сняты в одинаковых viewport и статичной фазе, не взяты из старого отчёта.

**Рефракция проверена отдельно от blur:** на той же сцене временно обнулены только SVG displacement scales. Изменились 818 пикселей более чем на 2 уровня канала, максимум 8/255. Тон, blur, фон, foreground и геометрия при этом сохранены. Эффект намеренно слабый. Исходные кадры и усиленная карта разницы лежат в sdk/refraction-*.png; карта разницы не является обычным видом сайта.

**Контраст на составном фоне:** SDK-сообщения ≥7.12:1; Hero CSS ≥5.90:1; продуктовый текст/выбор ≥5.79:1. Метод: снимок с временно скрытым text-fill без изменения геометрии, исходный foreground против каждого второго пикселя под диапазоном текста. Отдельно проверены normal/hover/focus/selected строк. Axe — 9 состояний внутри браузерного набора. Это не проверка экранным диктором.

**Жизненный цикл:** css не обращается к GPU; отсутствующий API, null/reject adapter, долгий probe, chunk failure, реальная diagnostic error с тестовым устройством — CSS без пропажи сообщений. Изменение preferences снимает эффект. Пауза проверена в середине reveal. При скрытии вкладки (эмуляция visibilitychange) и уходе далеко за viewport фильтры сняты, созданные GPU devices уничтожены; после возврата содержание сохранено. Root margin 200px и задержка 750ms не пересоздают сцену на каждом пикселе границы. При освобождении последнего потребителя через 2s очищаются карты и renderer. Late resolve, timeout, повторный cleanup и схема StrictMode setup/cleanup/setup проверены unit-тестами адаптера; это не отдельный запуск React StrictMode в browser dev build. Полный переход на главную проверен отдельно; его reload не выдаётся за измерение React unmount.

## Производительность и ограничения

Первый SDK-start в отдельном browser run: 86.8ms от probe до готовности двух карт, diagnostic mapTime 23.0ms. Прогретый replay измерялся 4.4s в том же Chromium/1440×900/DPR1: CSS rAF median 8.3 / p95 9.2ms; SDK 8.3 / 9.2ms. В обоих образцах нет gaps >50ms и long tasks. Это интервалы callbacks в данной среде, не гарантия FPS и не тест Safari. Синтетическое click→два rAF: CSS 11.3ms, SDK 10.0ms; это не INP.

SDK lazy-загрузка добавляет 247,149 bytes JS / 83,867 bytes gzip в этой сборке. Сумма всех JS chunks проекта выросла на 253,506 bytes / 85,926 bytes gzip. Результат не объявляется «бесплатным» визуальным эффектом.

Safari/WebKit: binary отсутствует, runtime не проверен. Реальные iOS/Android, Firefox и screen reader не проверены. Safari и touch/coarse/mobile UA в auto получают CSS. Phone viewport в Chromium — эмуляция размеров, не тест телефона. Автоматическое включение SDK ограничено desktop Chromium и успешным adapter probe.

Настоящий browser zoom 200% не подтверждён: отдельный профиль и Meta+Equal через Playwright не изменили CSS viewport/DPR. Проверены увеличение root text до 200%, spacing и reflow, включая 320px. Файл zoom-probe.json фиксирует различие. Физическая потеря GPU-device не воспроизводилась; diagnostic failure и cleanup проверены.

Npm tarball не содержит WebKit-правки контрольного commit; это существенное ограничение версии. [Точный аудит SDK](glass-sdk-audit.md).
