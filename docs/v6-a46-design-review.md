## Реализовано

**Стекло.** Сравнены свежая A4.5 regular/dark + tint#163362 и итоговая clear/dark без tint. Выбран clear: прежний tint почти скрывал локальный рисунок. Входящее теперь дымчатое сине-сапфировое: тот же рисунок виден снаружи и внутри кромки. За белым текстом — мягкий полупрозрачный radial scrim Navy (78→76→38%), без непрозрачного прямоугольника. Цвет букв сохранён; текст — резкий DOM без filter/scale.

Исходящее переведено с сероватого regular/light на clear/light с Paper/Ice 42% и лёгким голубым тоном sampled SVG. contextStrip прозрачен, OMS остаётся белым. Одна матовая оболочка, один локальный SVG, две SDK-поверхности; новых линз вокруг страницы нет. CSS — самостоятельный матовый вариант. Радиусы 24/20px, поля, кегли и геометрия сообщений совпадают с A4.5 и между CSS/SDK на всех восьми измеренных ширинах.

SDK **0.0.1**, package.json, lockfile и все 52 файла установленного SDK неизменны. Используются документированные material/appearance/radius/refraction; refraction 10 desktop / 6 compact. Выдуманный fillOpacity, правки shader/node_modules и новые зависимости не применялись. Ранее установленный npm dist не становится main/commit8795d30; исторический [аудит версии](glass-sdk-audit.md) остаётся справкой, а новые runtime-результаты находятся в этом отчёте.

**Движение.** Выбраны неподвижные линзы + движение только sampled-света. Рисунок перемещается максимум на 4 SVG единицы по X / 2 по Y и возвращается в исходную точку. Небольшой световой блик появляется внутри рисунка, не поверх текста. Всё подчинено существующему clock4200ms, без отдельного бесконечного shimmer/таймера. Окно, сообщения, подписи и CTA не перемещаются. При paused/hidden/offscreen clock останавливается, completed неподвижен; resume продолжает фазу.

CSS transition opacity удалён у reveal, чтобы он не продолжался после паузы независимо от clock. Поверхность проявляется за380ms; семантический текст показывается после её проявления с полным контрастом. При паузе посередине поверхность может ещё быть без текста — это намеренное исключение бледных букв. Reduced-motion, contrast-more, reduced-transparency и forced-colors показывают статичную полную историю. No-JS сохраняет её целиком.

**Темы и сетка.** Все desktop-пункты шириной336px, Inter18px, padding18×24, gap12 и постоянный слот16px для галочки. Мягкая форма, цвет состояний, названия и порядок сохранены. Mobile: обе активные темы занимают доступную ширину; Inter17px, padding16, gap8. Даже на320px все подписи в одну строку при100%; при200% текста разрешён естественный перенос.

Общие переменные контейнера задают nav-track, reading-start и gap одновременно для шапки и содержимого. Reading-start — clamp(nav-track+32px,32%,nav-track+160px), ширина чтения до640px. Измеренный X текста «Решение» и группы содержания совпадает: максимум0px. Скрытие badge не сдвигает ось. Закрытая группа всех тем остаётся на верхней опоре CRM, выбор OMS/разработки не опускает её.

Шапка становится компактной при1120px до столкновения ссылок с CTA; тематический breakpoint900px сохранён. Материал шапки — white92% в начале /86% после скролла, blur16px и тихая кромка. Без blur и при reduced-transparency/contrast — opaque white; forced-colors — системные цвета. CTA, hover, Hero-оффер/композиция, локальные шрифты, логотип, footer и шесть содержательных текстов сохранены.

## Контраст, оптика и пауза

Контраст измерен по фактическому композитному изображению: временно скрывался text-fill без изменения layout, исходный foreground (с учётом opacity) сравнивался с каждым вторым пикселем под диапазоном текста, включая самый светлый. Скрытые до конца reveal буквы не выдаются за читаемый текст.

- Статичные SDK-сообщения на5 ширинах: минимум6.64:1.
- **66 промежуточных/конечных состояний**: CSS/SDK ×1920/430/390 ×11 фаз, минимум6.17:1 для видимого текста сцены. Mobile-фазы сняты в высоком viewport1600px для измерения всех строк; это не экран телефона.
- Hero CSS normal/no-blur/contrast: минимум5.91:1; все темы с раскрытиями: 5.80:1.
- Header над белым, Sapphire и Navy, с blur и без него: минимум4.506:1. Header-аудит использует локальные контрольные фоны, которых нет в продукте.
- Normal/hover/focus/selected тем проверены отдельно. Axe проверяет desktop/mobile, форму и варианты материалов; это не screen-reader audit.

On/zero refraction проверен **отдельно для каждого сообщения**, менялся только displacement scale на той же живой сцене. Incoming: 617 пикселей с delta>2, max16/255. Outgoing: 696 пикселей, max32/255. Карты не заменяют визуальную оценку: проходящий фон и кромка просмотрены в обычном100% размере.

Шесть проверок pause (2режима ×3ширины) в середине reveal: PNG области истории **побайтно совпадают** через500ms; свет, elapsed и bounds совпадают. Resume продолжает время, replay проходит один цикл. После10 реальных полных циклов: 2 surfaces, 2 maps, 1 GPU-device, 1 texture, одна регистрация сцены; active interval остаётся1, timers не растут. MapTime неизменен 24.7ms. Это diagnostic duration карты, не стоимость каждого кадра. Линзы не двигаются, поэтому рассинхронизации положения с картой нет.

Cleanup/timeout/ownership прежнего адаптера не изменены. Отказ API/adapter/chunk/renderer и поздние promises проверены; CSS остаётся видимым. При hidden (симуляция visibilitychange) и удалении сцены далеко за viewport фильтры снимаются, GPU-device уничтожается после grace; возврат восстанавливает2 поверхности. Возврат с offscreen и full-document navigation проверены отдельно. Полный reload не выдаётся за тест React unmount в браузере; async cleanup и схема setup-cleanup-setup покрыты unit-тестом.

## Производительность и пределы проверки

До/после — тот же Chromium,1440×900,DPR1, прогретый цикл4.4s. В финальном измерении не запускались другие браузерные проверки.

| Режим | Before median /p95 | After median /p95 | After max |
|---|---|---|---|
| CSS | 8.3/9.7ms | 8.3/9.7ms | 10.4ms |
| SDK | 8.3/9.7ms | 8.3/10.1ms | 11.4ms |

Это интервалы rAF callbacks, **не FPS и не INP**. В обоих финальных образцах нет gap>50ms и long task. Первый cold-start нового browser-run 79.3ms, mapTime 25.6ms; эти локальные цифры не являются обещанием скорости на других устройствах. GPU lazy-overhead: 247149bytes JS /83867gzip. CSS/public GPU-код не получают.

**Не проверено:** Safari/WebKit (binary недоступен), Firefox, реальные iOS/Android, screen reader, физическая потеря GPU, настоящий browser zoom200%. Размеры mobile/DPR2 — эмуляция Chromium. Проверен text resize200%, не эквивалент zoom. Auto-policy для непроверенных движков/touch/mobile оставлена CSS. P1 mobile SDK lens остаётся deferred. Новых внешних настроек или доступов для этого локального кандидата не требуется.
