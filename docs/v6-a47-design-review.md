## Результат

Incoming: спокойный Sapphire → Navy, белый текст; outgoing: молочный Ice, Navy-текст. Полупрозрачность находится в материале. Оба CSS backdrop-filter, тонкая светлая кромка и мягкая тень; в no-blur/contrast/transparency — законченная непрозрачная версия. Внешнее окно одно матовое, контекст прозрачен, OMS белый. StoryBackdrop содержит два широких статичных поля, без маршрутов/бликов/stroke-трасс.

Рассказ длится 6000 ms, вход сообщения — подъём 10 px с settle 480 ms. Сообщение появляется целиком с текстом при opacity=1, буквы не включаются в последнем кадре. Затем оба bubble продолжают перемещаться: 8400/10200 ms, ±1/±1.5 px X и ±3/±4 px Y, на mobile амплитуда вдвое меньше; envelope 800 ms. Общая Pause/Resume и отдельный Replay (доступен после завершения). Один императивный clock; React получает только смену состояния/этапа. Родитель сцены, контекст, OMS, оффер и CTA не парят. Без JS / при предпочтениях доступности история полная и статичная.

Футер Navy, один контактный CSS-блок, неизменные email/домен/юридические ссылки. Высота desktop около 359 px, без фиксированной высоты. Длинная ссылка переносится даже при 200% текста + увеличенных интервалах. В первых проверках найдены и исправлены overflow от свечения на 901/1024 и перенос privacy-ссылки при 320 + text spacing.

## Политика SDK

**Auto = CSS во всех браузерах.** SDK 0.0.1, package.json, lockfile и все 52 файлов установленного SDK сохранены. `glass=sdk` — диагностический режим с максимум двумя реальными поверхностями. Использован публичный `addAnimator`: общий clock обновляет translate самой зарегистрированной поверхности до измерения геометрии SDK. Повторное получение одного rAF timestamp не удваивает время. Никаких трансформированных родителей, движущихся только букв, shader edits или обновлений пакета.

Проверка optical-on против тех же кадров с displacement=0 дала максимум 1/255 у incoming и 2/255 у outgoing; пикселей с delta>2 нет. На тихом фоне полезная рефракция не подтверждена, а clip-path SDK обрезает CSS-тень. Поэтому прежний критерий положительного optical gain не пройден: исходный `motion/audit.json` сохраняет этот FAIL как свидетельство решения о CSS-auto. Это не замаскировано статусом enhanced. Статус maps=2 означает готовность карт, а не качество эффекта. Заметной задержки между буквами и поверхностью на просмотренных кадрах нет; субкадровая задержка не измерялась. Safari SDK не форсировался.

Исходная проверка ошибочно требовала равенство числа завершающихся animations; исправлена на отсутствие роста, исходные измерения сохранены.
