- Wide/fine/hover: две bubble движутся ±0.6/±0.8px по X и ±1.5/±2px по Y, периоды 8400/10200ms. Compact-policy: max-width900 ИЛИ pointer:coarse ИЛИ hover:none. На compact — один проход 6000ms, затем прекращение собственной цепочки rAF. Кнопка Pause становится Replay в том же DOM-узле; фокус и место controls сохранены. Resize/input change не сбрасывает прочитанную историю и userPause; изменение амплитуды плавно settles за 320ms общего clock.
- Footer: отдельная footerBottom на полную ширину для legal + nav. На 1920/1728/1440/1366/1024 четыре ссылки стоят в одном ряду. На узком экране навигация намеренно вертикальная. Контакты максимум360px, поля16/20, radius18, fill6/8%, кромка14%; наружный glow удалён. Высота широкого футера **275px**, ранее **359px**, без height/max-height. ## OMS и фон

48 состояний на1920/430/390: 0/120/240/480,3000/3120/3240/3480,**4490/4500/4540/4620/4740/4920/5100/6000ms**. Реальный production controller получает управляемые rAF timestamps; целевое и фактическое время сохранены в `entry/audit.json` и совпадают. Это покадровый функциональный тест, не измерение производительности. Есть обычные кадры и отдельная проба со скрытым foreground при неизменном layout. Минимальный измеренный композитный контраст **5.33:1**.

Внутренняя область фона побайтно одинаковая во всех фазах; размеры shell/background не меняются. Полный raster не во всех повторениях идентичен: на сглаженных внешних краях/углах различия до2/255, численные данные сохранены. В A4.7 также не воспроизведена смена внутреннего фона по стадии; там видна постоянная вложенная плита, которую позднее перекрывает OMS. Это не объявляется багом Safari. A4.8 убирает геометрическую причину, а не маскирует её белой карточкой.

Пауза на4620ms дала идентичные PNG на всех3ширинах. Добавлен отдельный browser test видимого входа OMS и freeze/resume без изменения геометрии. Первый вариант теста мог принять округлённую отметку4500ms за уже видимую карточку. Тест исправлен: ждёт запуска истории, реальную visibility и4540ms. Первый неуспешный результат сохранён в `browser-first-run.json`; финальная полная серия60PASS выполнена после исправления, покрытие не удалялось.

## Реальное время и ресурсы

Свежие записи: desktop **30.96s**, mobile390×844 **18.88s**. Есть Pause/Resume во время входа OMS, завершённая история и Replay. В desktop после завершения двигаются обе bubble, контекст/OMS неподвижны. В mobile между завершением и поздним кадром: **0 новых requestAnimationFrame callbacks,0 DOM mutations сцены**, pending RAF=0, время и translate неизменны. При Replay время снова идёт с начала. Замеры сделаны в Chromium на Mac с эмуляцией touch/viewport; это не FPS физического телефона.

Visibility API simulation: hidden10s — время неизменно, resume250ms добавил250ms; настоящий scroll/IntersectionObserver — offscreen время неизменно, возврат добавил233ms за250ms. UserPause сохранён. Resize900↔901 и смена input fine↔coarse проверены без автоматического replay и рывка paused-позиции. Единственный clock и SDK callback не удваивают одинаковый timestamp. Lifecycle/timeout/cancellation проверяют сохранённые unit/browser тесты; реальная потеря GPU не воспроизводилась.
