## Что показано

Светлый Hero с оригинальным знаком TMS и короткой предметной историей: обращение → сохранённые договорённости → передача заказа → действие команды. DOM/CSS-сцена не изображает действующую клиентскую систему. Нет вымышленных клиентов, сумм, отзывов или «ИИ онлайн». Цикл занимает 3,6 секунды, запускается один раз при появлении сцены; доступны пауза, продолжение и повтор. Reduced-motion и no-JS показывают осмысленный финальный вариант сразу.

Оффер и оба CTA взяты из последнего предложения владельца без изменения смысла. «Обсудить задачу» открывает изолированный макет формы; «Как работает TMS» переводит к продуктам этой страницы. Ссылка в учебное `/demo` не используется как CTA. Сам маршрут сохранён.

Продуктовый раздел показывает CRM и OMS равноправно: одинаковая ширина карточек, оба целиком видны на большом десктопе. Третья карточка разработки доступна через нативную горизонтальную прокрутку, стрелки, подписанный переключатель и клавиатуру. Ссылки ведут на существующие продуктовые страницы. Нет автопрокрутки и перехвата вертикального колеса. Под лентой — продолжение общего процесса CRM + OMS.

Футер компактный, Navy #000926. Использованы подтверждённые ООО «ТМС», ИНН 6900030390, tmsasub@yandex.ru, tmsasub.store. На телефоне контакты и документы следуют за брендом, затем навигация и реквизиты. Нижней закреплённой CTA нет.

В раскрываемых «Материалах для согласования» доступны шесть состояний кнопки, четыре отдельные авторские роли, образец стекла и черновая последовательность будущих разделов. Остальные секции сайта на этом этапе не переделаны.

## Источники и предложенные решения

Приоритет — актуальный запрос и V6 approval pack. Прочитаны START, brief 01–06, 27 ответов владельца, VISUAL_INDEX, точные JSON/CSS-токены, применимый AGENTS.md и документация установленного Next. Визуально просмотрены пять исходных изображений: 01-glass-chat, 02-gradient-button-figma, 03-shadow-figma, 04-screen-composition-1920-figma и 08-desired-dark-footer. Сырые изображения и документы пакета не добавлены в public.

Точно сохранены стекло #1F356E / 8%, border #D6E6F3 / 14%, входящее #122654, исходящий градиент #0F52BA → #3B88FF, normal/hover синей кнопки, отдельные белая и градиентные роли. Акцент 0/55/100% и его border не объединены с hover обычной кнопки. Тень — 0 8px 20px, Navy / 8%. Alpha применяется к материалу, не ко всему тексту.

Предлагаются к утверждению: композиция окна и его цветная подложка, скругления, расстояния, типографическая иерархия, pressed/disabled/loading и контур фокуса. Под белым текстом яркого сообщения добавлен локальный Navy / 24%: исходный градиент сохранён по краям; без этой поддержки его яркий конец не давал 4,5:1. В текущем составном фоне минимум сообщения — 5,492:1. При отсутствии backdrop-filter предусмотрен непрозрачный Paper-фон. Это проектное решение явно показано в preview.

[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) использован как ориентир слоёв и сдержанности материала; CSS не объявляется воспроизведением нативного Liquid Glass. SF и брендинг Apple не использованы. Другие внешние сайты не использовались как источник обещаний о TMS.

Свежие HTTPS GET к [TMS Auto](https://tmsasub.store/auto/) и [TMS Realty](https://tmsasub.store/nedv/) вернули 200 и разные содержательные страницы. Результаты — `qa/v6/external-links.json`. Первоначальные попытки через web-инструмент/DNS песочницы были недоступны; прямое разрешённое HTTPS-чтение завершилось успешно. Функции отраслевых продуктов в preview не добавлены. Будущий root-deploy должен сохранить оба маршрута.

Разрешение владельца на обезличенную публикацию трёх кейсов зафиксировано в `content-approvals.md`; повторное разрешение не требуется. Публичная редакция кейсов, периоды, ограничения и математика калькуляторов не изменены. Полный юридический текст и реальные интеграции остаются отдельными условиями запуска.

## Сохранность и изоляция

Рабочая папка не содержит Git metadata, поэтому ветка/коммит не создавались. До редактирования сделан отдельный безопасный снимок 125 файлов с SHA-256 в `work/baseline-v6-current`; сравнение с приложенным V5: 102 совпадения, 0 изменённых, 0 отсутствующих файлов. Baseline не распаковывался поверх проекта.

Маршрут `app/review/v6/page.tsx` находится вне marketing layout. Стили ограничены CSS module и корнем preview; общие глобальные стили не заменены. `components/Analytics.tsx` исключает `/review/` из загрузки Метрики, capture UTM и обработчиков аналитики. Остальные изменения прежних файлов — README и запись подтверждений в content-approvals. Итоговые хеши — `qa/v6/isolation-audit.json`.

Review требует серверного `TMS_DESIGN_REVIEW=1` и loopback Host/forwarded Host. Штатный launcher привязывает сервер только к 127.0.0.1, отключает доставку и tracking-конфигурацию. В обычной сборке/запуске флаг выключен и маршрут возвращает 404; чужой Host и forwarded Host также дают 404. Noindex/nofollow/noarchive и отсутствие sitemap дополняют ограничение доступа. Не используйте launcher через публичный reverse proxy: это локальный стенд, а не авторизация публичного staging.

Форма не вызывает API, не сохраняет поля и не сообщает о доставке. Валидное заполнение даёт только «Это проверка макета — обращение не отправлено». Native dialog, Escape, удержание/возврат фокуса, ошибки и прокрутка проверены. Без JS форма недоступна, и это явно объяснено; история, ссылки, продукты и native mobile menu остаются доступны.

## Как открыть и повторить

Из корня `outputs/tms-site`:

```sh
npm run build
node scripts/review-v6.mjs
```

Для браузерных проверок нужен также временный второй сервер, где review выключен:

```sh
TMS_DESIGN_REVIEW=0 TMS_HOST=127.0.0.1 PORT=3201 LEADS_WEBHOOK_URL='' LEADS_WEBHOOK_TOKEN='' LEADS_LEGAL_APPROVED=false npm run start
npx playwright test -c playwright.v6.config.ts
node scripts/capture-v6.mjs
node scripts/contrast-v6.mjs
python3 scripts/contrast-v6.py
```

Два capture/test процесса одновременно не запускать. После проверки второй сервер можно остановить.
